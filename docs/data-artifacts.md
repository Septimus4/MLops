# Data & Artifacts

Understanding where data and models live is critical for reproducibility and compliance. This page documents the key locations and formats.

## Training Inputs

- **Dataset directory:** `home-credit-default-risk-DATA/`
- **Expected files (subset):**
  - `application_train.csv`, `application_test.csv`
  - `bureau.csv`, `bureau_balance.csv`
  - `previous_application.csv`, `installments_payments.csv`
  - `credit_card_balance.csv`, `POS_CASH_balance.csv`
- `src/data_prep/data_prep.py` orchestrates loading, cleaning, and feature engineering.

## Artifacts for Inference

Located under `artifacts/`:

- `feature_defaults.json` – median values used to backfill missing inputs.
- `categorical_mappings.json` – label encodings for categorical features.
- `feature_list.json` – ordered feature names expected by the model.

These artifacts are cached by the API and shared with monitoring code to ensure consistent schema handling.

## Model Registry

Directory: `model_registry/`

- `registry.json` tracks promoted models with metadata (version, path, threshold, registration timestamp).
- `home_credit_model_v_<timestamp>.pkl` files store XGBoost booster objects.
- `best_model_summary.json` summarises the latest promotion (metrics, threshold, training tags).

Override the default model by setting `MODEL_PATH` or `MODEL_VERSION` via environment variables.

## Runtime Data

`data/` contains operational logs and derived metrics:

- `logs/YYYY-MM-DD.jsonl` – append-only event stream capturing every request.
- `metrics/daily/*.parquet` – optional Parquet compaction (generated by `scripts/compaction.py`).
- `metrics/drift/latest_drift_report.html` – rendered Evidently report.
- `metrics/drift/latest_drift_report.json` – machine-readable summary used by `/metrics`.
- `reference/` – baseline samples and statistics refreshed by `scripts/make_reference_snapshot.py`.

Ensure the directory is mounted or persisted in production deployments so historical data is not lost.

## Documentation & Specs

- `docs/` – MkDocs source for this documentation site.
- `docs/openapi/openapi.json` – generated OpenAPI schema for the FastAPI service (see `scripts/generate_openapi.py`).

## Backup Guidance

- Version control handles code and most static artifacts; avoid committing large datasets or operational logs.
- Store sensitive data (e.g., real applicant information) outside the repository; replace with synthetic or anonymised samples for demos.
- Consider snapshotting `model_registry/` and `data/reference/` whenever you promote a new model so inference artifacts remain reproducible.
